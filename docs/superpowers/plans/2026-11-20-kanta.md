# Kanta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android music hub that shows the MixPlay-style screens, keeps one library/queue across Spotify, YouTube Music, Apple Music and local files, and plays them by controlling the installed apps (local files: played by Kanta itself).

**Architecture:** Expo/React Native app (screens, library, playlists) on a local SQLite database, plus a local Kotlin Expo module `kanta-media` that runs in the background: a `NotificationListenerService` that reads and controls other apps' media sessions, a native queue engine, a history logger, and a Media3 player for local files with real EQ/crossfade/gapless.

**Tech Stack:** Expo SDK 57, React Native 0.86.3, expo-router, TypeScript, zustand, expo-sqlite, Reanimated 4, vitest (with Node's built-in `node:sqlite` for DB tests); Kotlin, AndroidX Media3, `DynamicsProcessing`, Spotify App Remote SDK (optional).

**Spec:** `docs/superpowers/specs/2026-11-20-kanta-design.md` — read it with this plan. Visual reference: `docs/design/MixPlay-reference.pdf`.

- Commits: one per phase at its checkpoint, only after the user OKs it. End messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Share links come in many shapes** (`?si=` tracking, `/intl-fil/` paths, `youtu.be`, `www.youtube.com` vs `music.youtube.com`, Apple Music album URLs with `?i=` track id) → each saves as the right source/kind/id. Tests in Task 3.2.
2. **The same song is titled differently** by the queue and the app ("Yellow" vs "Yellow - Remastered 2021", artist "Coldplay - Topic") → the queue engine must not treat it as a different song and skip. Tests in Task 4.1.
3. **A source app is uninstalled, or notification access is turned off** mid-use → Sources/Home show a clear state and a fix button; controls do nothing instead of crashing. Tests in Task 2.1.
4. **Offline or unknown links** → the song is still saved with its link and a placeholder title; details fill in on the next open. Lyrics show "No lyrics found" rather than spinning forever. Tests in Tasks 3.3 and 5.1.
5. **Empty library, no history, nothing playing** → every tab renders guidance (not blank lists). Tests in Task 3.6 (pure section builders) + manual check at the Phase 3 checkpoint.
